**Задание 3. Автотесты для UI**

Автотесты для проверки веб-интерфейса (UI) сервиса Stellar Burgers(https://stellarburgers.education-services.ru/)

Реализованные проверки:
• Основная функциональность: навигация (переходы на страницы «Конструктор» и «Лента заказов»); вызов всплывающего окна деталей ингредиента и его успешное закрытие по клику на крестик; динамическое увеличение счётчика на карточке ингредиента при его переносе
• Раздел «Лента заказов»: увеличение глобального счётчика «Выполнено за всё время» при поступлении нового заказа; увеличение счётчика «Выполнено за сегодня»; отображение номера только что созданного заказа в списке раздела «В работе».

Процент покрытия 100% (отчет Allure: http://127.0.0.1:1915/#suites/bbe0d669efc706ee57875a7e22880e98/9fa56655b10a1b72/ )

Структура проекта:
• Директория tests/: содержит UI-сценарии, сгруппированные в тест-классы по логическим модулям (test_page_navigation.py, test_ingredients.py, test_order.py)
• Директория pages/: реализует паттерн Page Object Model. Содержит базовый класс со стандартными обёртками над Selenium (base_page.py) и классы с бизнес-логикой конкретных страниц приложения (navigation_page.py, ingredients_page.py, order_page.py).
• Интеграция с API и кроссбраузерность: для стабильности и скорости прохождения тестов Ленты создание заказов реализовано фоновыми API-запросами в фикстурах; обеспечена полная кроссбраузерность тестов в Google Chrome и Mozilla Firefox
